# Smart Content Hub

A full-stack adaptive learning and content discovery platform designed to provide highly personalized educational journeys.

## Key Features

*   **AI-Powered Recommendations:** Integrates a hybrid recommendation engine combining content-based filtering (TF-IDF & cosine similarity) and collaborative filtering (Surprise SVD).
*   **Multi-Format Content:** Seamlessly manages and recommends across multiple content types, including articles, video lectures, and interactive quizzes.
*   **Full-Stack Architecture:** 
    *   **Backend:** Powered by Django, handling machine learning models, user management, and data exports.
    *   **Frontend:** A responsive React application providing an intuitive interface for content consumption.

## Project Structure

- **`backend/`**: The Django API service handling machine learning, data storage, and business logic.
- **`frontend/`**: The React client interface for users to consume personalized content.

## Getting Started

Please refer to the respective directories (`backend` and `frontend`) for specific instructions on how to set up, run, and deploy each component.
